API

The HTTP API is small enough to fit on this page. All endpoints return JSON unless they're streaming a file. Base URL is https://drop.pensa.ar.

POST /upload

Upload a file. multipart/form-data with a file field.

Parameters

All optional. Accepted as form fields or query params (query wins).

NameTypeDefaultDescription
expires_inint (seconds)3600How long the file lives. Max 604800 (7 days).
one_shotboolfalseIf true, delete after the first successful fetch.
filenamestring—Override the uploaded filename. Sanitized.

Example

curl -F "file=@report.pdf" \
  "https://drop.pensa.ar/upload?expires_in=86400&one_shot=true"

Response — 201 Created

{
  "url":           "https://drop.pensa.ar/f/aB3xK9-mnP2qR/report.pdf",
  "id":            "aB3xK9-mnP2qR",
  "filename":      "report.pdf",
  "size_bytes":    26817,
  "sha256":        "66fef8...",
  "content_type":  "application/pdf",
  "expires_at":    "2026-05-08T22:00:00Z",
  "expires_in_seconds": 86400,
  "delete_url":    "https://drop.pensa.ar/f/aB3xK9-mnP2qR?token=zT8w...",
  "one_shot":      true
}

Save the delete_url if you want to be able to delete the file later. The token is shown once and never recoverable.

Errors

  • 400 — invalid filename, bad expires_in
  • 413 — file exceeds 50 MB limit
  • 415 — file extension is blocked (e.g. .exe)
  • 429 — rate limited (30 uploads/hour per IP)

GET /f/{id}/{filename}

Download the file. Streams the body with the original content-type (HTML and SVG are downgraded to text/plain for safety).

Query params

NameTypeDescription
download0 or 1If 1, force Content-Disposition: attachment.
render0 or 1If 1, serve HTML/SVG with their real type. Unsafe.

Example

curl -O "https://drop.pensa.ar/f/aB3xK9-mnP2qR/report.pdf?download=1"

Errors

  • 404 — file not found, expired, or filename mismatch
  • 410 — one-shot file already consumed
  • 416 — Range header invalid or unsatisfiable
  • 429 — rate limited (200 fetches/min per IP, 100/hour per file per IP)

Range requests

Single byte ranges are supported per RFC 9110: bytes=N-M, bytes=N-, and bytes=-N. The server advertises support via Accept-Ranges: bytes in successful responses. Multi-range requests (e.g. bytes=0-9,20-29) are not supported and return 416. 

curl -H "Range: bytes=0-1023" "https://drop.pensa.ar/f/<id>/<name>"
# → 206 Partial Content
#   Content-Range: bytes 0-1023/<total>
#   Content-Length: 1024

On a one-shot upload, a partial range request does not consume the file — only a full read (no Range, or a Range covering the whole file) consumes it. This makes range probes safe for metadata reads (video/PDF headers).

HEAD /f/{id}/{filename}

Same as GET but returns headers only. Useful for liveness probes.

GET /f/{id}/info

Return public metadata without serving the body.

Example

curl https://drop.pensa.ar/f/aB3xK9-mnP2qR/info
{
  "id":            "aB3xK9-mnP2qR",
  "filename":      "report.pdf",
  "size_bytes":    26817,
  "sha256":        "66fef8...",
  "content_type":  "application/pdf",
  "created_at":    "2026-05-07T22:00:00Z",
  "expires_at":    "2026-05-08T22:00:00Z",
  "one_shot":      true,
  "fetched_count": 0
}

DELETE /f/{id}?token={delete_token}

Delete a file by ID, authorized by the delete token returned at upload.

Example

curl -X DELETE "https://drop.pensa.ar/f/aB3xK9-mnP2qR?token=zT8w..."

Response — 200 OK

{ "deleted": true, "already": false, "id": "aB3xK9-mnP2qR" }

Idempotent. Calling delete on an already-deleted file with the same token returns 200 with already: true.

Errors

  • 403 — invalid or missing token, or file unknown (responses are indistinguishable to prevent ID enumeration)
  • 429 — rate limited

GET /healthz

Health check.

{ "ok": true, "files_count": 12, "storage_used_mb": 18.7 }

Rate limits

  • Uploads: 30/hour per IP. Stricter (10/hour) for cross-origin browser callers.
  • Fetches: 200/minute per IP, plus 100/hour per (file_id, IP) pair.
  • Deletes: 60/hour per IP.

Exceeding any of these returns 429. Wait, then retry.
