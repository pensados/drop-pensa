Privacy

The short version: we don't log your file contents, we don't sell anything, we don't track you across the web. We log enough to operate the service and investigate abuse. Files are deleted on the schedule you choose.

What gets stored

For each upload, we record:

  • The file itself, on disk, until it expires or is deleted.
  • Its filename, size, content-type, and SHA-256 hash.
  • The IP address of the uploader.
  • Timestamps for upload, expiry, and most recent fetch.
  • A SHA-256 hash of the delete token (never the token itself).

What does not get stored

  • The contents of files in any log or index. Files exist only on disk, in their raw form.
  • The delete token in plaintext. Only its hash. If you lose the token, the file can't be deleted on demand — it'll still expire automatically.
  • Cookies, sessions, or any client-side storage. The web UI keeps state only in memory while the page is open.
  • Third-party analytics, fingerprints, ad pixels, or social embeds.

How long things are kept

  • Uploaded files: until the expiry window you chose (1 hour to 7 days). One-shot files are deleted on first fetch.
  • Database rows: soft-deleted on expiry, hard-deleted 24 hours later by the cleanup worker.
  • Logs: structured JSON access logs, kept for 30 days, then rotated. Used for abuse investigation only.
  • Backups: none. If a file is deleted or expired, it's gone.

Why we log IPs

Two reasons. First, to enforce rate limits (30 uploads per hour per IP, etc.) so one client can't crowd out everyone else. Second, to investigate abuse — if someone uses the service to distribute malware or illegal content, we may share the upload IP with the relevant authorities under applicable law.

We do not share IPs or any other data for commercial purposes.

Your URL is your secret

The file URL contains a random ID with about 78 bits of entropy. That's far more than enough to make guessing infeasible. But anyone you give the URL to can fetch the file. If you paste it in a public chat, indexers will find it. If you DM it to one person, only they can fetch it.

For sensitive content, use one-shot mode and delete the file from the recipient's view after they confirm receipt.

Cookies

None. The site sets no cookies, period.
