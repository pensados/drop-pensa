About

drop.pensa.ar is a file drop service. You upload a file, you get back a public URL, and the file expires after a window you choose. The URL is the secret — anyone with the URL can fetch the file until it expires or you delete it.

Why this exists

There are two main use cases this serves. The first is human: sometimes you want to send someone a file in a chat, an email, or a message, and you don't want to attach a 30 MB binary or sign up for a file-sharing service. You drop the file here, copy the link, paste it, move on. The second is automation: scripts, AI agents, and CI tasks often need to expose a file briefly — a build artifact, a generated report, a screenshot. A POST returns a URL, the URL gets fetched once or twice, and the file disappears.

Both cases want the same thing: low friction, predictable expiry, nothing to clean up.

How it works

  • You pick a retention window — 1 hour, 6 hours, 24 hours, or 7 days.
  • You optionally mark the file as delete after first download.
  • The server stores it on disk, generates a hard-to-guess ID, and returns a URL.
  • Anyone with the URL can fetch the file. Without the URL, the file is unreachable — IDs have around 78 bits of entropy, so they're not guessable.
  • When the window elapses, a background worker deletes the file from disk and the database row.

What it isn't

drop.pensa.ar is not end-to-end encrypted. The server can read the file. If the contents are sensitive, encrypt before uploading or use a different tool.

It's also not a hosting service. HTML and SVG files are served as plain text to neutralize XSS. Don't try to host a website here.

There's a 50 MB per-file limit. For larger files, look elsewhere.
